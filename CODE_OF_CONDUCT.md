# Code de conduite

## Notre engagement

En tant que membres, contributrices et contributeurs, nous nous engageons à faire de la participation à Lanterne une expérience sans harcèlement pour tout le monde, quels que soient l'âge, la taille, le handicap visible ou invisible, l'origine ethnique, les caractéristiques sexuelles, l'identité ou l'expression de genre, le niveau d'expérience, l'éducation, le statut socio-économique, la nationalité, l'apparence, la religion ou l'orientation sexuelle.

Nous nous engageons à agir et à interagir de manière à contribuer à une communauté ouverte, accueillante, diversifiée, inclusive et saine.

## Nos standards

Exemples de comportements qui contribuent à un environnement positif :

- faire preuve d'empathie et de bienveillance envers les autres ;
- respecter les opinions, les points de vue et les expériences différents ;
- donner et recevoir avec élégance des retours constructifs, en particulier lors des revues de code ;
- assumer ses erreurs, s'excuser auprès des personnes concernées et en tirer des leçons ;
- privilégier ce qui est le mieux pour le projet et l'équipe, et pas seulement pour soi.

Exemples de comportements inacceptables :

- les propos ou images à caractère sexuel, et les avances de toute nature ;
- le trolling, les commentaires insultants ou désobligeants, et les attaques personnelles ou politiques ;
- le harcèlement, en public comme en privé ;
- la publication d'informations privées d'autrui, comme une adresse postale ou électronique, sans permission explicite ;
- toute autre conduite raisonnablement considérée comme inappropriée dans un cadre professionnel.

## Champ d'application

Ce code de conduite s'applique dans tous les espaces du projet : dépôts, issues, pull requests, revues de code, GitHub Projects, ainsi que les échanges de l'équipe liés au projet. Il s'applique aussi lorsqu'une personne représente le projet en public, par exemple lors d'une soutenance.

## Signalement

Les comportements contraires à ce code de conduite peuvent être signalés **en privé** :

- par le formulaire de signalement privé du dépôt (onglet **Security**, puis **Report a vulnerability**), en précisant qu'il s'agit d'un signalement de conduite ;
- ou par message direct à un membre de l'équipe qui n'est pas concerné par le signalement (voir la section [Équipe](README.md#équipe) du README).

Ne signalez pas un comportement dans une issue ou une pull request publique. Tous les signalements sont traités rapidement et avec équité, et l'équipe respecte la confidentialité de la personne qui signale.

## Application

L'équipe est responsable de l'application de ce code de conduite. Selon la gravité, elle peut :

1. **Corriger** : échange privé et explication de la raison pour laquelle le comportement était inapproprié.
2. **Avertir** : avertissement écrit, avec les conséquences en cas de récidive.
3. **Suspendre** : interdiction temporaire d'interagir dans les espaces du projet.
4. **Exclure** : interdiction définitive d'interagir dans les espaces du projet.

Si le signalement concerne un membre de l'équipe et ne peut pas être réglé entre nous, il est transmis au référent pédagogique.
